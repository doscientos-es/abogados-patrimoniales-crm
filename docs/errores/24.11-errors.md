## Contactos y búsqueda (errores 1–5)

### Error 1 · NIF con letra errónea se guarda

**Prioridad: Media · Ruta: /contactos/nuevo**

- Pasos: Nuevo contacto → NIF 11111111A → Crear contacto.

- Resultado: se guarda sin aviso. Ya hay contactos antiguos con la letra mal: 12345678A, 64454446T, 15915915L. El propio placeholder (12345678A) es incorrecto: la letra buena es Z.

- Esperado: validar la letra de control (DNI/NIE: módulo 23 sobre TRWAGMYFPDXBNJZSQVHLCKE; CIF con su dígito de control). Avisar en rojo y no dejar guardar sin confirmar.

![Captura del documento, página 3](Informe_errores_LEX_EUS_beta_imagenes/pagina-03-captura-01.png)

### Error 2 · Correo sin dominio se guarda

**Prioridad: Media · Ruta: /contactos/nuevo**

- Pasos: Correo miren.prueba@ejemplo (sin .es/.com) → Crear contacto.

- Resultado: se guarda. Ficha: /contactos/d9ee9850-f5c9-4b8d-a193-9f7735441f9b.

- Esperado: exigir dominio con TLD (el type=email del navegador no lo hace por sí solo).

Captura: la misma del error 1.

### Error 3 · El código postal no autocompleta

**Prioridad: Baja · Ruta: /contactos/nuevo**

### Error 4 · La búsqueda no ignora tildes

**Prioridad: Media · Dónde: buscador global (Ctrl K)**

- Pasos: buscar lopez.

- Resultado: sale ANA LOPEZ, pero no ANA LÓPEZ LÓPEZ.

- Esperado: búsqueda insensible a tildes y mayúsculas (en Postgres: extensión unaccent + ilike, o columna normalizada).

- Extra: al abrir el buscador con clic, el cursor no se coloca en el campo de texto.
